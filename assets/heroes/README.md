# Loghi personaggi

I PNG locali del selettore vengono generati da `scripts/generate_logos.py` mantenendo questi nomi:

- `ironman.png`
- `thor.png`
- `capitan-america.png`
- `hulk.png`
- `spiderman.png`

Se un file manca, l'interfaccia mostra il fallback `LOGO` senza interrompere il caricamento del tracker.
